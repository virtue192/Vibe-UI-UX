# 0.5.1.0.0：特效广场与统一界面

该分支同时包含此前 0.5 工作台改造。提交或推送分支不等于已合并和部署，线上版本以 Pages 成功部署为准。

## 行为变化

- 主页面统一采用米白、浅橄榄绿、简洁系统字体与卡片风格；保留既有效果的真实交互。
- 全站广场、我的投稿、提交特效入口；工作台预览区直接携带合法效果快照投稿。
- 真实官方特效、已收录案例、GitHub 待审核队列、搜索 / 类型 / 排序 / 分页、独立投稿详情。
- 三步投稿、合法 JSON / 项目版本导入、公开许可确认、长正文复制、尚未确认状态、客户端关联及 Issue URL 关联。
- 当前标签页草稿与可选本机跟踪；没有新增用户账号、服务端凭据、自动收录或部署权限。
- 结构校验与真实审核边界区分；当前 PR 内容不匹配最新投稿时等待同步，合并与官网发布区分。

## 验证记录

自动测试覆盖旧工作台功能和新的状态、来源、分页、匿名请求、客户端 ID、链接关联、导入及 CSP 边界。浏览器检查见随交付的记录，包含读取真实待审案例、精确参数进入工作台、工作台快照进入投稿表单、准备链接仍未确认和响应式布局。

测试未创建真实公开投稿，也未修改既有作者的 Issue / PR。没有在本次任务中执行完整的真实作者提交、机器人修改 / 撤回、维护者审核合并、官网部署闭环；这些不能算作新版本已验证。既有机器人的历史验证详见旧发布记录。

## 限制

- 公开 GitHub API 查询受匿名额度和网络影响；当前版本不是服务端静态索引和登录式“我的投稿”。
- 审核意见仍在 GitHub；不虚构站内审核后台和通知。
- 原创代码只提供 Web 契约；组合、片段与视频素材还不能作为社区单效果投稿。
- 新社区长说明对日 / 韩 / 德使用英文回退；真实设备、Safari / Firefox、付费模型和多人首次使用测试未在本次完整执行。

详见 [广场使用说明与数据边界](COMMUNITY_PLAZA.md) 和 [0.5 工作台验证范围](RELEASE_0.5.0.0.0.md)。
